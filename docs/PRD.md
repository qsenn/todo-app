## 1. Why - 목적

- 일일 할 일과 장기 목표 사이의 연결 단절 해소
- 할 일 → 주간 계획 → 1년 목표의 계층 구조로 실행과 목표 정렬
- 상태 변경만으로 주간 진행률 자동 반영, 수동 집계 제거
- 드래그 앤 드롭 기반으로 상태 관리 부담 최소화

## 2. Who - 타깃 사용자

- 연간 목표를 세우고 주 단위로 실행 계획을 관리하는 개인 사용자
- 일일 할 일은 관리하지만 목표 대비 진척도 파악이 어려운 사용자
- 칸반 방식(todo/doing/done)의 시각적 상태 관리를 선호하는 사용자

## 3. User Flow

1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표에 연결
3. 일일 할 일 생성 → 주간 계획에 연결
4. 칸반 보드에서 할 일 확인 (todo / doing / done)
5. 드래그 앤 드롭으로 할 일 상태 변경
6. 상태 변경 시 주간 진행률 자동 재계산
7. 주간 계획 및 1년 목표 화면에서 진행 현황 확인
8. 필요 시 할 일 / 주간 계획 / 1년 목표 수정·삭제

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **할 일 CRUD**
  - 생성: 제목, 날짜(일일), 연결할 주간 계획, 상태 (기본값 todo)
  - 조회: 날짜별 / 주간 계획별 목록
  - 수정: 제목, 날짜, 연결 주간 계획, 상태
  - 삭제: 삭제 시 주간 진행률 재계산
- **상태 관리**
  - 상태값: todo / doing / done
  - 할 일 1건당 상태 1개
- **드래그 앤 드롭 상태 변경**
  - 칸반 보드 3개 컬럼 (todo / doing / done)
  - 컬럼 간 이동 시 상태 즉시 업데이트
  - 이동 결과 즉시 저장
- **기간 구조**
  - 일일: 할 일 (특정 날짜)
  - 주간: 주간 계획 (특정 주, 시작일~종료일)
  - 연간: 1년 목표 (특정 연도)
  - 주간 계획 / 1년 목표 CRUD 지원
- **구조 연결**
  - 할 일 → 주간 계획 (N:1)
  - 주간 계획 → 1년 목표 (N:1)
  - 연결 대상 변경 가능
  - 상위 항목 삭제 시 하위 항목 처리 규칙 정의 (연결 해제 또는 삭제 확인)
- **주간 진행률 자동 반영**
  - 계산식: 연결된 할 일 중 done 개수 / 연결된 할 일 전체 개수 × 100
  - 트리거: 할 일 생성 / 삭제 / 상태 변경 / 연결 변경
  - 연결된 할 일 0건일 경우 0% 표시
  - 주간 계획 화면에 진행률 표시

### P1 - 추가 기능

- **1년 목표 진행률**
  - 연결된 주간 계획 진행률 기반 집계
  - 1년 목표 화면에 표시
- **일일 진행률**
  - 해당 날짜 할 일 done 비율 표시
- **계층 뷰**
  - 1년 목표 → 주간 계획 → 할 일 트리 형태 조회
- **주간 계획 미연결 할 일 관리**
  - 미연결 할 일 목록 별도 표시
  - 목록에서 주간 계획으로 연결
